# AI Chat Saver

A premium, lightweight Manifest V3 Chrome Extension that allows you to save and manage conversations across 36+ AI chat platforms with a single click.

## Features

- **Multi-Platform Support**: Works out-of-the-box on 36+ popular AI interfaces (ChatGPT, Claude, Gemini, DeepSeek, Perplexity, etc.).
- **Dual-Mode Saving**: 
  - Save full conversation threads from page headers.
  - Save individual user prompts or assistant responses using context-aware hover stars.
- **Searchable Dashboard**: A custom New Tab page dashboard to search, filter by platform, delete, and view message logs in a modal.
- **Glassmorphism Design**: Elegant UI transitions and overlays that adapt perfectly to both light and dark system settings.
- **Dynamic Platform Addition**: A settings panel to add custom LLM hostnames (e.g. self-hosted Ollama, Local WebUIs) using dynamic Manifest V3 scripting registration.

## Installation & Setup

1. Clone or download this repository:
   ```bash
   git clone https://github.com/manjunath-27-idea/ai-chat-saver.git
   ```
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** (top-right toggle).
4. Click **Load unpacked** (top-left button) and select the `ai-chat-saver` directory.
5. Pin the extension to your toolbar. Click the icon to launch the dashboard!
